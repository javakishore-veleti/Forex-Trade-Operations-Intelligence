# Vector Store (VECTOR_STORE role)

pgvector extension on PostgreSQL 16 — provides vector similarity search for:
- **Similar-incident retrieval** — agents find past trade failures similar to the current one
- **Rule corpus search** — agents search rule descriptions by semantic similarity

## Port
- `5433` (distinct from the main RELATIONAL_STORE on 5432)

## Tables
- `incident_embeddings` — past incident embeddings (1536-dim, cosine distance, HNSW index)
- `rule_embeddings` — Drools rule description embeddings

## Connection
```
postgresql://fxops_vector:${VECTOR_STORE_PASSWORD}@localhost:5433/fxops_vectors
```

## Cloud Target Bindings
- **AWS**: Amazon RDS PostgreSQL with pgvector extension (or Amazon OpenSearch with kNN)
- **Azure**: Azure Database for PostgreSQL Flexible Server with pgvector (or Azure AI Search)

## Embedding Model
Embeddings are generated by the Python sidecars (specifically the log-normalizer sidecar
has embedding capability). The embedding dimension is 1536 (OpenAI text-embedding-3-small
compatible, but any model producing 1536-dim vectors works).

## Usage
```bash
docker compose -f DevOps/Local/vector-store/docker-compose.yaml up -d
```
