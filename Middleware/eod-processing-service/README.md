# eod-processing-service

End-of-day batch processing and settlement reconciliation. Handles daily position aggregation, P&L calculation, and settlement matching at market close.

## Technology

- Java 21
- Spring Boot
- Maven

## Configuration

- `spring.application.name`: `eod-processing-service`

## How to Run

```bash
mvn spring-boot:run
```

## How to Test

```bash
mvn test
```
