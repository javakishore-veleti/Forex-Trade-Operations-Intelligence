# trade-ingest-service

Ingests incoming trade events into the platform. This service acts as the entry point for all trade data flowing into the Forex Trade Operations Intelligence system.

## Technology

- Java 21
- Spring Boot
- Maven

## Configuration

- `spring.application.name`: `trade-ingest-service`

## How to Run

```bash
mvn spring-boot:run
```

## How to Test

```bash
mvn test
```
