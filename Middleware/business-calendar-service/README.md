# business-calendar-service

Business day and holiday management for trade scheduling. Determines valid settlement dates, handles market holidays across multiple jurisdictions, and provides date arithmetic for trade lifecycle events.

## Technology

- Java 21
- Spring Boot
- Maven

## Configuration

- `spring.application.name`: `business-calendar-service`

## How to Run

```bash
mvn spring-boot:run
```

## How to Test

```bash
mvn test
```
