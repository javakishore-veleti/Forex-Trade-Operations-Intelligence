# trade-lifecycle-service

Manages trade state transitions through the lifecycle. Tracks trades from initiation through execution, confirmation, settlement, and maturity.

## Technology

- Java 21
- Spring Boot
- Maven

## Configuration

- `spring.application.name`: `trade-lifecycle-service`

## How to Run

```bash
mvn spring-boot:run
```

## How to Test

```bash
mvn test
```
