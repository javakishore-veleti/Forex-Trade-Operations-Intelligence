# risk-calculation-service

Computes risk metrics for active trade positions. Provides real-time and batch risk calculations including exposure analysis, margin requirements, and position limits.

## Technology

- Java 21
- Spring Boot
- Maven

## Configuration

- `spring.application.name`: `risk-calculation-service`

## How to Run

```bash
mvn spring-boot:run
```

## How to Test

```bash
mvn test
```
